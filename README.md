## Текущий режим

**Серверный приём через Telegram включён.** Заявки сохраняются в отдельной PostgreSQL, отправляются привязанному менеджеру @qazfuel и ожидают его решения. Вход проверяется на сервере по Telegram initData. Заявки доступны только владельцу; бронь на трассе действует 24 часа с создания, независимо от времени подтверждения.

Проверены настоящая доставка двух служебных сообщений и оба действия менеджера в Telegram. Эти записи явно помечены как проверки, реальной бронью не являются. Старые локальные и обычные серверные демозаявки не превращаются в реальные и не отправляются менеджеру автоматически.

Свежей проверенной региональной котировки нет — показывается «Цена уточняется». Правило цены: рынок **минус 3 ₽/л**, скидка фиксирована. Наличие топлива и окончательные условия подтверждает менеджер.

Бесплатная PostgreSQL действует **до 29 ноября 2026**; нет управляемых резервных копий. Для постоянной коммерческой работы нужна отдельная договорённость о хранении и резервировании. Платные ресурсы не создавались.

## Структура

- `v3/` — текущий мобильный интерфейс, Leaflet и девять точных координат.
- `server/` — Node API, PostgreSQL, серверная валидация, авторизация, история статусов, подключённая защищённая Telegram-интеграция.
- `tests/` — бизнес-правила, регрессия WebKit, серверные пользовательские сценарии, публичный smoke-тест.
- `docs/STAGE2_*` — актуальные результаты и ограничения. Более ранние отчёты описывают предыдущие версии.
- `public/` и корневой `render.yaml` — **прежний действующий сайт**. Не применять его Blueprint для V3 и не менять main/production.

## Проверки и локальный запуск

```sh
npm ci --prefix server
npm install --prefix tests
node --test tests/core.test.cjs
npm test --prefix server
node tests/e2e.cjs
node tests/stage2.e2e.cjs
node tests/live-smoke.cjs
```

Для браузерных тестов нужны Playwright WebKit и его системные зависимости. `tests/stage2.e2e.cjs` запускает отдельные локальные API и PostgreSQL engine, не обращаясь к production. `tests/live-smoke.cjs` проверяет текущий публичный live-режим без создания реальных заявок. Старый `tests/public-smoke.cjs` предназначен только для фазы server_test и создаёт явно помеченные тестовые записи; не запускайте его как проверку live-приёма.

Статический локальный просмотр: `python3 -m http.server 8000 --directory v3`. Для автономного локального демо задайте `apiBase:''` в локальной копии `v3/config.js`; не публикуйте эту локальную настройку в тестовый сервис. Сервер: `node server/index.js`, DATABASE_URL и секреты задаются переменными окружения.

## Границы релиза

Main и действующий сайт не изменялись. По отдельному разрешению владельца кнопка @QazFuelServiceBot переключена на V3, обновлены описание и команды; подключение менеджера и проверка уведомлений описаны в docs/TELEGRAM_CONNECT.md. Токена бота нет в репозитории или клиенте. Настоящая доставка и решения менеджера подтверждены. Использованный при настройке токен нужно отозвать и заменить напрямую в Render; webhook защищён отдельным секретом. Устаревшие отчёты этапа 2 сохранены как история, текущее состояние — в TELEGRAM_CONNECT.md.

Меню менеджера, ручные цены, закрытие точек и ограничения напоминаний: [инструкция](docs/MANAGER_OPERATIONS.md).
