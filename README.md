## Текущий режим

**Серверный тест**: заявки действительно сохраняются в отдельной PostgreSQL и загружаются после перезапуска приложения. Они не отправляются менеджеру и не создают реальную бронь. Тестовые подтверждение/отклонение отмечены явно. Старые записи браузера остаются локальными и не загружаются в базу автоматически.

Проверенная региональная котировка отсутствует — показывается «Цена уточняется». Подключённые серверные адаптеры реально запрашивают источники, проверяют регион и дату, кешируют ответы, но не выдают непригодные данные за текущую цену. Правило цены: рынок **минус 3 ₽/л**, скидка фиксирована.

Бесплатная тестовая PostgreSQL действует **до 29 ноября 2026**; нет управляемых резервных копий. До коммерческого запуска нужна отдельная договорённость о постоянной базе и резервировании. Платные ресурсы не создавались.

## Структура

- `v3/` — текущий мобильный интерфейс, Leaflet и девять точных координат.
- `server/` — Node API, PostgreSQL, серверная валидация, авторизация, история статусов, защищённая Telegram-интеграция (отключена).
- `tests/` — бизнес-правила, регрессия WebKit, серверные пользовательские сценарии, публичный smoke-тест.
- `docs/STAGE2_*` — актуальные результаты и ограничения. Более ранние отчёты описывают предыдущие версии.
- `public/` и корневой `render.yaml` — **прежний действующий сайт**. Не применять его Blueprint для V3 и не менять main/production.

## Проверки и локальный запуск

```sh
npm ci --prefix server
npm install --prefix tests
node --test tests/core.test.cjs
npm test --prefix server
node tests/e2e.cjs
node tests/stage2.e2e.cjs
```

Для браузерных тестов нужны Playwright WebKit и его системные зависимости. `tests/stage2.e2e.cjs` запускает отдельные локальные API и PostgreSQL engine, не обращаясь к production. `tests/public-smoke.cjs` создаёт явно помеченные тестовые заявки только на V3 preview — это проверка с записью тестовых данных.

Статический локальный просмотр: `python3 -m http.server 8000 --directory v3`. Для автономного локального демо задайте `apiBase:''` в локальной копии `v3/config.js`; не публикуйте эту локальную настройку в тестовый сервис. Сервер: `node server/index.js`, DATABASE_URL и секреты задаются переменными окружения.

## Границы релиза

Main, действующий сайт и настройки @QazFuelServiceBot не изменялись. Токена бота нет в репозитории или клиенте. Настоящая доставка уведомлений не проверена и не объявлена работающей. Для следующего шага нужны подтверждённый ID/chat менеджера, секреты в Render и отдельное разрешение на интеграцию с действующим webhook либо отдельный тестовый бот.
