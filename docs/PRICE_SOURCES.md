# QAZFUEL V3 — проверка открытых источников цен

Проверено 30 октября 2026 года реальными HTTPS GET-запросами из среды разработки. В запросах передан Origin: https://qazfuel-v3-preview.onrender.com. Ниже — наблюдавшиеся ответы, а не гарантия доступности в будущем.

## Результаты

| Источник / запрос | Фактический ответ | Ограничение для QAZFUEL |
|---|---|---|
| https://eh-ai.ru/api/ | HTTP 404 | Страница документации недоступна прямому HTTP-клиенту в момент проверки; поисковый fetch страницы без завершающего слеша вернул документацию |
| https://eh-ai.ru/assets/prices.json | HTTP 200, application/json, 526 байт | `updated=1783786806`, `updated_h=11.07.2026`: срез старше 100 дней; есть только `brands`, нет `regions` и АИ-98; заголовок Access-Control-Allow-Origin отсутствует |
| https://eh-ai.ru/api/openapi.json | HTTP 404 | Актуальный машинный контракт не получен |
| https://wherefuel.ru/for-business | HTTP 200 | Документация описывает бесплатный анонимный доступ для тестов и коммерческий тариф по согласованию |
| https://wherefuel.ru/api/stations?bbox=37.3,55.5,37.9,55.9 | HTTP 200, application/json | 924 АЗС; ни одной записи с полем цены; все updatedAt=null; Access-Control-Allow-Origin отсутствует |
| https://wherefuel.ru/api/clusters?bbox=37.3,55.5,37.9,55.9&zoom=10 | HTTP 200, application/json | Кластеры наличия, не цены; Access-Control-Allow-Origin отсутствует |
| https://openvan.camp/api/fuel/prices | HTTP 200, application/json, Access-Control-Allow-Origin: * | Есть RU, RUB/литр, fetched_at=2026-10-26T06:04:22+03:00; национальный срез, не региональные цены |

Wherefuel: во всех 924 станциях набор полей ограничен `address`, `brand`, `city`, `confirmations`, `id`, `lat`, `lng`, `status`, `updatedAt`. Наличие самой АЗС не доказывает наличие топлива или актуальной цены. Отсутствие CORS-заголовка не блокирует серверный GET, но не позволяет считать доказанной прямую интеграцию из браузера preview-сайта.

OpenVan: фактически возвращены ключи `gasoline`, `gasoline_premium`, `gasoline_super`, `diesel`; проверенная документация не устанавливает однозначное соответствие российских марок АИ-95/АИ-98 этим ключам. Не подменять АИ-98 значением premium по предположению. Указана лицензия CC BY 4.0 и обязательная видимая атрибуция OpenVan.camp рядом с данными. Даже после проверки соответствия марок эти значения можно показывать лишь как национальный справочный ориентир, не как рынок Москвы или конкретной трассовой точки.

## Решение для текущего preview

Ни один проверенный ответ не обеспечивает одновременно АИ-95, АИ-98, ДТ, регион, свежую дату и безопасную прямую браузерную загрузку. Не публиковать выдуманные либо устаревшие цены. Показывать «Региональная цена не подключена»; ручной калькулятор клиенту не показывать. Стартовая цена QAZFUEL: актуальный рынок из API минус фиксированные 3 ₽/л; без валидного ориентира итоговую сумму не вычислять. «Полный бак» — без неизвестного количества и ложного расчёта суммы.

## Следующее подключение

Серверный адаптер с таймаутом, кэшированием, проверкой валюты/единицы/марки/региона/даты, отбрасыванием устаревших данных и сохранением атрибуции. Для Wherefuel согласовать коммерческий сценарий, покрытие цен и ключ; секретный ключ не помещать в клиент. Для Ехай дождаться свежего регионального среза и получить подтверждение наличия АИ-98. Росстат публикует региональные таблицы, включая категорию «АИ-98 и выше», но это не доказанный готовый API и не точная марка АИ-98.

## Первичные источники

- https://eh-ai.ru/api/ — контракт и условия; актуальность ответа проверена отдельно, не принята на веру.
- https://wherefuel.ru/for-business — доступ, условия и endpoints.
- https://wherefuel.ru/news/ceny/metodika — ограничения покрытия и происхождение цен.
- https://openvan.camp/ru/developers — бесплатный API, CORS, лицензия и поля.
- https://openvan.camp/.well-known/openapi.json — спецификация.

Никакие учётные записи, платные тарифы, ключи и серверные ресурсы в рамках этой проверки не создавались.
