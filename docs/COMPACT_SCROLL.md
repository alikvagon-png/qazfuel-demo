# Компактность и обычная прокрутка объёма

Изменены только клиентские HTML/CSS и удалён один ResizeObserver, измерявший плавающий блок. Сервер, расчёт Росстата, права, уведомления и данные не меняются.

Из .delivery-volume удалены старые sticky/fixed, смещения и ограничение высоты. Удалены резервные верхние отступы страницы и специальное скрытие быстрых кнопок при клавиатуре. Новое положение static в обычном потоке; блок перемещён перед типом топлива. Ползунок и полный бак сохраняются. Поля прокручиваются с отступом только под шапку, без бывшей высоты плавающего блока.

У точек сокращены отступы заголовка/карты/списка. Название занимает строку, страна и цена делят следующую; координаты раскрываются; обе кнопки остаются минимум 44 px. У заявок сокращены отступы заголовка, фильтров, карточки и метаданных. Цвета и шрифты сохранены.

Тест tests/compact-scroll.e2e.cjs проверяет WebKit 320/375/390/430/768: порядок блоков, позицию, реальное смещение панели вместе с scrollY и уход выше экрана, 40/80 литров и суммы, полный бак, доступность кнопок при классе клавиатуры, отсутствие горизонтального переполнения. API в этом тесте явно подменён локальными фикстурами; реальные цены и API проверяются отдельно существующим публичным smoke. Без создания реальных заявок.

Исходная высота обычной карточки с доступной ценой: 187,23 px при всех пяти размерах; после компоновки — 138,98 px, сокращение примерно на 25,8% (71 проверка прошла). Раскрытые координаты, закрытая точка или длинное предупреждение закономерно увеличивают высоту. Полная регрессия карты/заказов: 82 сценария.

Настоящий iPhone Telegram недоступен в среде: проверяется WebKit и мобильная эмуляция. Main и старый сайт не меняются.
