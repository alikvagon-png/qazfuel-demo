# Этап 3: Росстат, Москва, единый ориентир

## Источник и контракт

Официальный каталог: https://rosstat.gov.ru/compendium/document/50798 . Выявленная публикация: https://rosstat.gov.ru/storage/mediabank/169_28-10-2026.html . Заголовок: «О потребительских ценах на нефтепродукты с 20 по 26 октября 2026 года», публикация 28 октября, дата статистики 26 октября 2026.

При исследовании индексированного официального материала подтверждена строка **г. Москва**, не Московская область: АИ-95 — 76,02; АИ-98 и выше — 102,17; дизель — 81,71 ₽/л. Соответствующий расчёт QAZFUEL — 73,02 / 99,17 / 78,71. Эти числа не являются загрузочным seed и не прописаны в производственной логике. Они используются в явно синтетических тестовых HTML-фикстурах. Реальный сервер показывает числа только после самостоятельного успешного импорта официального документа или защищённой загрузки файла менеджером.

Из текущей среды прямые запросы к каталогу и HTML Росстата возвращали HTTP 503 (proxy: remote connection failure); поисковый индекс официальной страницы доступен. Это не доказывает работоспособность прямого импорта с Render. Фактическое состояние видно в `/api/prices`: import.last_attempt, last_success, last_error, next_attempt и importMethod каждой котировки. Не выдавать тесты с синтетическим HTML за реальное скачивание Росстата.

## Импорт

`server/rosstat.js` разрешает только HTTPS и официальный домен rosstat.gov.ru/www.rosstat.gov.ru, ограничивает объём, время запроса и перенаправления. Выбирает ссылки HTML из реального каталога, не угадывает номера файлов. При сбое каталога пробует последний сохранённый официальный URL, а при первом запуске — конкретную ссылку, проверенную в исследовании выше. Значения цен в коде отсутствуют. Такой режим помечается rosstat_catalog_unavailable и не гарантирует обнаружение самой новой публикации до восстановления каталога; повтор через час. Таблицы разбираются Cheerio с rowspan/colspan. Проверяются заголовок нефтепродуктов, единицы рублей за литр, единственная отчётная дата, единственная точная строка Москвы и три независимых столбца АИ-95, АИ-98 и выше, дизель. Пропуск категории, непонятная структура или неверные числа отклоняют весь импорт, предыдущая таблица сохраняется.

PostgreSQL хранит append-only версии котировок, дату, официальный URL, hash документа, способ и время импорта. Старые даты не заменяют новые. Исправление за ту же дату создаёт новую версию, истории заказов не меняются. Ручной импорт не выдаётся за автоматический (admin_file / admin_url).

Успех: следующая проверка через 6 часов. Ошибка: повтор через час, без удаления данных. Ошибка пишется в журнал. Срок статистики свыше 21 дня помечается как устаревший; последняя проверенная цена остаётся доступной как явно устаревший предварительный ориентир. Данные недельные, не real-time.

## Периодичность и бесплатный Render

Проверка запускается при старте, каждую минуту проверяет постоянное расписание, также запускается запросом GET /api/prices, если срок подошёл. Межпроцессная lease в PostgreSQL предотвращает параллельные импорты. Нет парсинга в браузере.

На бесплатном Render сервис засыпает: во время сна расписание не исполняется. После пробуждения первая просроченная проверка запускается автоматически. Строго гарантировать проверку каждый календарный день без внешнего планировщика нельзя. Платный worker/cron не создан. Бесплатный внешний монитор может вызывать https://qazfuel-v3-api.onrender.com/api/prices каждые 6 часов. GitHub scheduled workflows запускаются только из default branch, поэтому для V3 не создавался фиктивно работающий cron в недефолтной ветке; main не менялся.

## Резервный официальный файл

С привязанного аккаунта менеджера откройте Mini App → цены. Блок импорта виден только при серверном isManager=true. Сохраните оригинальную официальную HTML-публикацию Росстата, укажите её полный официальный URL, выберите файл и нажмите «Проверить и импортировать». Обрабатывается сервером тем же строгим парсером; скрипты из файла не исполняются. Поддерживаются UTF-8 и Windows-1251. Запрос /api/admin/rosstat-import требует верифицированную сессию Telegram, совпадение с привязанным менеджером и разрешённый Origin; есть лимит размера и частоты. Произвольные цифры не принимаются.

## Единый расчёт и заявки

Все экраны читают /api/prices. Один дизель Москвы применяется ко всем девяти точкам, без подмены смысла местной ценой. Каждая точка содержит соответствующее пояснение. Главная, каталог, доставка, ползунки, предварительная проверка и карточки показывают один источник.

Расчёт в целых копейках: unit=market-300, total=unit*целое число литров. Для полного бака цена за литр сохраняется, сумма null (по фактическим литрам). Цены браузера сервер отклоняет. При создании сервер читает актуальную постоянную котировку и сохраняет pricing в неизменяемом payload: цену рынка, цену QAZFUEL, сумму, регион, дату, URL, версию формулы, идентификатор котировки, признак устаревания и способ импорта. Повтор отправки возвращает исходную заявку с исходной ценой. Повтор заказа заполняет новую форму и получит новую котировку при новой отправке.

Заявки, созданные раньше этого этапа без pricing, остаются «Цена уточняется»; им не присваивается сегодняшняя цена. Telegram менеджеру содержит сохранённый расчёт, а не текущую цену. Новые типы сообщений проверены транспортным mock, реальная доставка сообщения с ценой требует тестового заказа после настоящего импорта. Настройки/секреты/webhook бота не менялись.

## Проверки

Серверные тесты выполняют SQL на PGlite: Москву и три категории, десятичный расчёт, новые версии, сбой источника, сохранение цены в истории, все девять точек, full tank, Telegram-текст и отказ неавторизованному импорту. WebKit e2e проходит настоящие локальные API/SQL с явно синтетическим HTML; проверяет все экраны, суммы, историю и размеры 320/390/430/768. Реальную доступность источника нужно оценивать отдельно от этих проверок.
