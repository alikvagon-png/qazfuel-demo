# Клиентская очистка QAZFUEL

Сохранён существующий дизайн, карта, авторизация, расчёт цены и система заявок. Main и старый сайт не затрагиваются.

## Интерфейс

Убраны видимая версия V3, служебная плашка приёма, повторяющиеся описания серверного хранения и ссылки «Цена без догадок»/«О ценах и источниках». Заголовок страницы — QAZFUEL. Реальные заявки не получают ярлыки «СЕРВЕР» и «БД». Служебные и учебные заявки по-прежнему явно обозначены и не выдаются за реальные. При локальном или серверном учебном режиме предупреждение остаётся; без входа предлагается открыть Telegram, при недоступности соединения — повторить подключение.

Главная содержит два сервиса, переход к заявкам, компактные три цены и короткое пояснение скидки. Прайс содержит название, цену, экономию, дату наблюдения, дату публикации (когда она известна из официального имени файла) и ссылку на Росстат. Нет клиентского селектора региона и административного обновления. Предварительный характер цены объяснён один раз; полное пояснение сохранено в форме и проверке заявки.

Карточки точек компактнее: название, страна, дизель, цена/дата, координаты в раскрывающемся блоке, маршрут и бронь. Одно общее московское пояснение расположено над списком. Закрытие точек, маркер → прокрутка/выделение, Яндекс и проверка на сервере сохраняются. Контактные размеры кнопок не менее 44 px.

«О нас»: описание направлений, три шага заказа, подтверждение менеджером, правило 24 часов, наличная оплата доставки, контакт менеджера, очистка данных устройства. Нет описаний внутренней архитектуры.

## Управление

Официальный HTML-импорт перенесён на отдельный экран «Управление ценами», переход из «О нас» виден только подтверждённому менеджеру. Клиентский переход к admin дополнительно блокируется; сервер POST /api/admin/rosstat-import независимо проверяет сессию и числовой ID менеджера. Скрытие HTML не является границей безопасности. Сам парсер, автоматическое расписание и резервный импорт не менялись.

## Telegram

В существующем защищённом profile-sync добавлено `setMyName({name:'QAZFUEL'})`. Действие выполняется только после getMe с точным username QazFuelServiceBot; успешно применённый профиль кешируется. Username, URL приложения, webhook, токены и привязка менеджера не меняются. Название HTML-страницы также QAZFUEL. Отдельный short name/настройки именованного приложения BotFather не меняются через неподдерживаемые методы; если такой отдельный заголовок сохранился, его следует проверить владельцу в BotFather.

## Проверки

Серверные тесты проверяют авторизацию, сохранность цен, уведомления, закрытие точек и запрет постороннего импорта. WebKit: 82 сценария регрессии, 42 проверки расчётов/истории, 277 проверок клиентской очистки на 320/375/390/430/768 px с двумя UI-ролями. Последний набор использует локальные транспортные фикстуры; серверная граница прав проверяется SQL-тестами отдельно. Реальный iOS Telegram и отдельная настройка заголовка BotFather требуют проверки с устройства владельца. Публичный прайс после деплоя проверяется настоящим API без подмены.
